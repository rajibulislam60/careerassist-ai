# 🚀 CareerAssist AI

> An AI-powered career development platform designed to help users build resumes, prepare for interviews, analyze skills, and receive personalized career guidance.

# 📌 Project Status

🚧 **Currently Under Development**

CareerAssist AI is being developed in two separate parts:

### Before Login
- Modern Landing Page
- Product Overview
- Features
- Pricing
- Testimonials
- Call to Action
- Responsive Design

### After Login
- AI Dashboard
- Resume Builder
- Interview Preparation
- Skill Analyzer
- Career Guidance
- AI Chat Assistant
- User Profile

Backend APIs, authentication, database integration, and AI services are currently in progress.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/rajibulislam60/careerassist-ai.git
```

## Go to project

```bash
cd careerassist-ai
```

## Install dependencies

```bash
npm install
```

## Run development server

```bash
npm run dev
```
